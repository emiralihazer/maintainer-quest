# Code of Conduct

Maintainer Quest is for learning sustainable open-source maintenance. Be patient,
specific, and respectful when discussing issues, contributors, users, and
maintainers.

## Expected behavior

- Assume good intent
- Give actionable feedback
- Keep disagreement focused on project goals and tradeoffs
- Make room for new contributors to learn

## Unacceptable behavior

- Harassment, insults, or discriminatory language
- Publishing private security details before a fix is coordinated
- Dismissing contributors because they are new
- Repeated off-topic or hostile comments

Maintainers may moderate issues, discussions, and pull requests to keep the
project useful and safe.
