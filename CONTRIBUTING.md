# Contributing

Thanks for helping improve Maintainer Quest.

## Good first contributions

- Add a realistic maintenance scenario
- Improve wording in an existing choice
- Fix accessibility issues
- Add translations
- Add small tests around scoring and endings

## Scenario guidelines

Each scenario should include:

- A clear maintainer problem
- Three choices with meaningful tradeoffs
- Effects on trust, quality, velocity, and maintainer energy
- Respectful language toward users, contributors, and maintainers

Avoid scenarios that reward hostile maintainer behavior or shame new contributors.

## Pull request checklist

- The game still runs by opening `index.html`
- Text fits on mobile screens
- Choices are keyboard accessible
- No external network assets are required
- New scenarios are grounded in realistic OSS work
