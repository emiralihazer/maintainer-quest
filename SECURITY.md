# Security Policy

Maintainer Quest is a static browser game with no backend service.

Please report security issues by opening a private advisory on GitHub if the
repository host supports it. If not, open an issue with a minimal description
that avoids publishing exploit details, and the maintainer will coordinate a fix.

## Scope

In scope:

- Cross-site scripting risks in scenario rendering
- Unsafe clipboard or local storage behavior
- Dependency or supply-chain issues if dependencies are added later

Out of scope:

- Social engineering
- Denial of service against local development servers
- Browser bugs unrelated to this project
